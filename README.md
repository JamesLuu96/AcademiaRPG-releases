# AcademiaRPG

## Download the latest version

**[Download AcademiaRPG for Windows](https://github.com/JamesLuu96/AcademiaRPG-releases/releases/latest/download/AcademiaRPG-Windows.zip)**

1. Download `AcademiaRPG-Windows.zip`.
2. Unzip it anywhere and run `AcademiaRPG.exe`.
   (Windows may warn about an unrecognized app: click **More info -> Run anyway**.)
3. To update, download the new zip and replace the old folder - your saves are kept separately.

The version is in the bottom-left of the title screen. 
Everyone needs the **same version**;

Steam must be running for online co-op.
